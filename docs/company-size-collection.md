# 企业规模与人数筛选（v0.15.1）

BOSS 与实习僧连接器在读取岗位时，同时保留页面明确标注的企业人数区间与行业。BOSS 支持岗位卡片、岗位详情侧栏和公司主页；实习僧支持岗位详情公司介绍、当前岗位的页面自带字段和公司主页。只读取人数标签，不从岗位描述、在招职位数、注册资本或品牌知名度推算。

先使用岗位页已有资料。人数缺失且页面明确关联公司主页时，复用本次任务的采集标签查看公司页；以平台公司链接去重，每批最多补查 8 次，不计入岗位详情次数，另外记录公司页访问次数。公司名称须与当前岗位一致，推荐区其他公司的内容不参与合并。发生访问限制或验证码时停止并保留已读岗位；普通公司页加载失败不会丢失 JD。

实习僧列表的数字可能使用特殊字体。连接器使用详情页正常显示的区间，或同一岗位对象里可读的规模原文，不猜测乱码数字。支持“0–20人”“500–2000人”“10000人以上”等区间，原始文字、独立来源链接及读取日期一起保存。只知道一端时保留另一端为空。

收件箱详情与入库表单直接显示企业规模，正常保存岗位时补全已有企业缺失的资料，没有额外确认步骤。未取得人数时显示“待录入”；用户也可直接填写人数或区间，来源链接选填。已有规模资料保持不变。平台区间不等于实时精确人数，也不保证与某个具体用工主体的口径相同。

岗位库、企业观察库、能力差距和 JD 统计都支持人数上下限滑块与精确数字输入。滑块使用非线性刻度，便于同时筛选几十人与数万人的企业。筛选采用区间交集：企业标注 100–499 人，筛选 200–500 人时会显示；人数只有一端时按开放区间处理。默认包含规模待录入企业，可取消勾选。岗位库与企业库的条件分别保存，滑动时只刷新结果，不打断拖动。

数字框输入过程中保留已生效的筛选；按回车或失焦后才应用完整数字，不会在输入首个字符时调整另一端。上下限填反时就地提示，保留原筛选供修改。能力差距中，人数条件没有匹配岗位时可清除人数筛选；有岗位但没有有效要求时才提示提取 JD。

编辑企业规模文字时，可识别的数字或区间会同步更新人数上下限。不能识别的新文字不会沿用旧数字，需改成明确的人数格式，或同时填写本次上下限。统计按数值上下限分组，合并连字符、空格等文字差异，企业详情仍保留原始文字。

Schema 26 移除旧分类列和分档偏好表，升级前自动保存完整 ZIP 备份。已有有效人数与来源保持；旧自由文本确实是人数区间时带入企业规模，分类名称不会被猜算成人数。正常接口、表单、统计和新导出都不再使用旧分类字段。

JD 会先安全保存到任务快照。公司查询结束后再一起提供给自动同步，避免提前同步漏掉规模；采集中断后仍能取回已保存的 JD。旧版本的实习僧详情缓存会失效，下一次采集重新读取。已有企业不会仅按名称批量联网搜索或套用集团规模；后续正常采集入库时按来源补缺。需要更细口径时可在企业资料中记录官网、年报等公开来源，不需要为这一字段单独配置付费接口。
