# 桌面工作台预览

Windows 桌面窗口与浏览器使用同一套前端。以下记录各版本的交互设计和验证方式。

## v0.17.0 界面验证记录（2026-11-12）

界面测试使用隔离数据库和虚构的企业、岗位及手动对应关系。已在 1366×900、980×650 完成名单导入、关联、连续整理、岗位筛选和分析范围检查。

- 名单页收拢为标题、摘要、当前操作和档案行；来源、下载、详细线索按需展开。
- 岗位库与 AI 工作台共用范围说明，显示企业名单、具体招聘主体及实际岗位数。
- 慢响应不会覆盖新草稿；清空勾选等待保存；局部保存保留搜索、状态、页码与附近条目。
- 千条名单与千家企业的隔离样本，第一页只展开当前20条完整候选；首次读取实测约0.33秒，耗时会随硬件及数据变化。
- 当时的 Windows WebView2 检查覆盖启动和页面进入。完整的导入、关联、保存、返回、筛选和分析流程在浏览器中验证。

## 查看本地界面

在项目目录运行：

```bash
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8785
```

打开 <http://127.0.0.1:8785>。服务已运行时刷新浏览器即可。
Windows 桌面开发入口沿用 `desktop.py`；UI 修改随原有 `desktop.spec` 进入桌面包。

## 早期设计记录

- 导航按收集、分析准备、求职进度分组，显示真实岗位与待核对数量。
- 搜索栏支持 Ctrl/Cmd+K；回车跳转岗位库，中文输入法组合期间保留输入框。
- 工作台将待核对资料、候选岗位、疑似重复和资料缺失直接连接对应页面。
- 岗位库增加结果数量与清除筛选；筛选栏在小窗口自动折行。
- 岗位详情使用岗位资料、来源与技能、投递记录三个标签页。
- 使用原生 dialog，Escape 关闭并恢复焦点，长表单保留可见保存入口。
- 窄屏可展开导航；收起的导航不参与键盘焦点，表格独立横向滚动。

## 验证方式

原有检查与本轮新增回归共 55 项通过；以下浏览器检查也已通过。独立截图复核结论为 ship，桌面、最小窗口和稳定状态的窄屏导航未发现需要修复的问题。

后端已有回归检查：

```bash
.venv/bin/python -m pytest -q
```

浏览器检查使用 Node.js 与已经安装的 Playwright / Chromium：

```bash
node tools/check_desktop_ui.cjs
node tools/check_ui_faults.cjs
```

Playwright 位于其他目录时，以 `RADAR_PLAYWRIGHT_MODULE` 指定其模块路径。
可设置 `RADAR_PYTHON` 指定项目 Python；设置 `RADAR_UI_SHOTS` 保存截图。
脚本自建临时 SQLite 和本机随机端口，退出时关闭服务并清除数据库。
验证覆盖 11 个页面、三个窗口尺寸、中文与全局搜索、筛选、弹窗键盘操作、岗位和投递保存、采集核对入库、CSV 预览与确认导入。

本轮验证在 Linux Chromium 中完成；Windows WebView2 原生窗口、EXE 打包和真实招聘平台登录操作需要在相应环境中检查。
