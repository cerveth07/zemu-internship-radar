# 岗位库与企业观察库分页

旧分页分支与主线整合后，岗位库保留较新的批量选择工作台，企业库接入可调整页长的分页器。

| 行为 | 岗位库 | 企业观察库 |
| --- | --- | --- |
| 页长 | 25 条 | 默认 12 家，可选 12 / 24 / 48 |
| 翻页 | 上一页 / 下一页 | 上一页 / 页码 / 下一页 |
| 选择 | 跨页保留，可导出或分析所选岗位 | 沿用档案、观察记录、关联岗位入口 |
| 筛选变化 | 重置第一页并清空选择 | 重置第一页 |

企业分页在卡片网格下方显示当前范围和总量。切换页长回到第一页；记录减少时自动修正越界页码。
空结果保持现有提示，只有一页且不超过最小页长时隐藏分页控件。

`selectedJobs()` 和 `selectedCompanies()` 返回完整筛选集合，分页仅作用于渲染；
导出筛选结果和分析所用的数据不会被当前页截断。岗位的「导出所选」另按勾选 ID 导出。

企业分页复用 `static/listing-pagination.js` / `.css`，岗位分页继续由 `static/job-bulk.js` 管理。
这不会减少首次 API 拉取量，属于客户端分页。

## 验证

- `tests/test_listing_pagination.py`：范围、末页、页长、越界、空结果和完整集合不被修改。
- `tests/test_task_bulk_actions.py`：较新岗位批量操作保持原有行为。
- `tools/check_branch_integration_ui.cjs`：真实浏览器验证企业 27 条分页、搜索复位、档案 ID、
  完整导出集合、岗位跨页选择、候选开关，以及 1320 / 980 / 390 像素布局。

浏览器检查使用临时数据库；不代表已完成打包后的 Windows WebView2 与 OCR 验收。
