# 个人材料、分析维护与成果回填（v0.14.1）

「能力准备 → 我的能力与经历」直接记录用户自述的能力、经历和作品。无需附件、作品链接或额外证明，也没有个人资料的核对状态。用户自己填写的内容直接保存，之后可以编辑，原编号和关联保留。

粘贴简历、项目说明或能力描述后即可保存，能力标签可以留空；添加、编辑和任务成果回填也遵循同一规则。一段经历可以关联多个能力。长材料按原文段落整理，原材料快照保留；应用不补写用户没有提供的成果。导入后提示保存的段数，并可直接查看我的经历。

分析建议可以调整或设为不采用，原始分析与修改记录保留。个人资料有更新时仅作提示，不阻止继续导入、使用建议或加入任务；顶栏文件导入和分析页内导入规则一致。AI 分析应基于用户自述，不得把缺少附件或没有提及某项能力当成能力不足。

从岗位档案调整建议、查看材料或登记成果，保存或取消后返回原岗位的原页签。修改多个引用经历时，未保存提醒比较全部选项。请求失败保留输入，并允许重试；只有服务器保存成功才显示成功。

每项行动都可以加入准备任务。共享任务展示全部关联岗位和要求。完成时可以直接把成果加入我的经历；这一步可选，保存的内容与其他用户填写资料一样使用。

材料版本可同时保存文本与最多 8 MB 的 PDF、DOCX、UTF-8 TXT、Markdown 原文件。PDF、DOCX 保存原件供下载；经历文本可以直接粘贴。从某版点击“保存新版本”，带入该版的文本，也可沿用原附件。每次更新材料产生新版本，投递绑定的旧版本不变。

桌面包的「数据与帮助」可复制实际安装路径的 MCP 配置，无需另装 Python 或取得源码。连接检测验证 stdio 握手、工具列表和本机接口。配置不含令牌；令牌由服务从本机读取。

空库首页提供粘贴 JD、导入个人经历、体验示例。示例明确标注为演示数据；已有岗位时不会注入示例。页面提供“结束体验并移除示例”，按预置记录识别示例，保留用户自己新增的内容以及已修改的个人经历、任务。投递追踪支持关键词、阶段、跟进安排筛选；“进行中未安排”的提示与筛选列表条件相同。总表优先显示已绑定材料，可直接打开，旧文字备注作为补充。

Schema 25 保留既有数据及原有接口名称，在 Schema 24 的材料版本、资料修改记录、建议调整、行动任务和成果关联上增加示例来源登记。升级会识别旧版预置示例，不按名称前缀删除。SQLite 完整备份包含附件；JSON 导出包含材料元数据与文本。

验收：直接保存一段经历 → 分析三个运营岗位 → 调整建议 → 完成共享任务 → 成果加入我的经历 → 投递绑定实际材料版本。未增加面试功能。
