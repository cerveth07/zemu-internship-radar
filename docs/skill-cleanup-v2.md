# 技能清洗 V2：三轮保守整理

数据依据：`data/collected/2026-10-22/`。原始归档有 1,978 项技能、4,059 条岗位关联；
清洗暂存区有 2,436 条候选关联、203 个实际出现的能力名称（交接词表 208 项）。

1. **无效学习项**：`general` 类别和明确的通用素质保留岗位参考资料，但标为
   `actionable=false`，排在可以专项学习的能力之后；不误删具有技能意义的长尾名词。
2. **同义归并**：需求和个人掌握状态统一经过数据库 `skill_aliases`；规范名
   个人状态优先于旧别名，避免“已满足”信息消失。不同层级不强合并：
   Agent基础/Agent开发/工具调用、RAG/向量检索、Vibe Coding/AI辅助编程。
3. **参考资料及强度核查**：JD 原文校验继续生效，对“必需但出现优先词”、
   “至少一种/之一”、否定条件和“加分无显式参考资料”生成 `curation_flags`。
   不凭整段文本的个别词擅自修改招聘方的 must/bonus；需要人工核对上下文。

运行时由 `app/skill_gap.py` 读取时生效，返回 `actionable` 和
`curation_flags`。原始技能、清洗候选、JD 参考资料、确认记录、压缩归档均不修改。
无数据库迁移；未对开发机本地 `radar.db` 执行写入。
